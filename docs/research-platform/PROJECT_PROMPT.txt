================================================================================

Tên: Research Platform trên UpBain
Mục tiêu: Hệ thống research Telegram — archive theo ngày VN, bot trả user,
           monetize VIP/Stars, share đua top, quản trị web.

  - 1 userbot (Pyrogram): thu thập batch, xếp sequence, up kênh RR

  - DB chỉ lưu: src_chat_id, src_msg_id, album_msg_ids[], seq, metadata ads
  - Khi user xem: bot PULL từ forum nguồn lúc đó (copy/forward)

Nguyên tắc ads (A1):
  - Hết hợp đồng: strip ads trong LẦN XEM archive sau
  - KHÔNG xóa tin ads user đã nhận trong chat cũ

Timezone: Asia/Ho_Chi_Minh
Label ngày: topic/tên ngày dạng 30-06-2026

5. LUỒNG NGHIỆP VỤ (implement theo spec — tham khảo repo chỉ khi stuck)
================================================================================

5.1 Một ngày VN
  Trigger (lịch / START / lệnh) → userbot collect batch nguồn
  → xếp seq + gắn ads alias → up kênh RR (L1)
  → ghi day_items vào DB (L2) → notify admin group
  → recheck ads aliases → admin Publish day
  → user /today hoặc /day → membership + VIP check
  → gửi tuần tự từng item từ nguồn (L3) → link share ngày

5.2 Delivery media (bài toán kỹ thuật — mượn Ý TƯỞNG clender _serve_album)
  Thiết kế yêu cầu:
    - Album: đủ msg_ids, không lệch seq
    - FloodWait: sleep, retry, không bỏ bài
    - Fallback khi copy fail: forward batch → từng msg
  → Viết hàm delivery riêng cho UpBain; tham khảo clender chỉ cho thứ tự fallback

5.3 Membership (mượn Ý TƯỞNG clender membership.py)
  Yêu cầu: chặn user chưa join kênh; cache; recheck; pending deep link
  → Implement trong stack aiogram + config UpBain; không paste file clender

5.4 VIP / Stars / Giftcode
  Web CRUD plans; bot /vip, /redeem, invoice XTR; grant admin tay
  → Thiết kế schema + handler phù hợp; UpBain nhánh cũ chỉ tham khảo flow

5.5 Share & đua top
  ref user + share ngày; numeric deep link; leaderboard 1 click/user
  → Token generator: có thể mượn ý clender generate_numeric_token

5.6 Backup & DR
  ZIP: DB snapshot + config masked + export index; rotate; scheduler; Telegram upload
  Resume: user_deliveries.last_seq_sent
  → Mượn ý clender backup loop + safe sqlite copy; format ZIP theo spec UpBain

5.7 Rollup 30 ngày
  Gom metadata thành text mục lục trên catalog topic; giữ lịch sử
