5. LUỒNG NGHIỆP VỤ CHI TIẾT
================================================================================

5.1 LUỒNG 1 NGÀY (VN 00:00–23:59)
---------------------------------

  1. Trigger: Lịch auto / START web / /runtopic
  2. Userbot collect batch từ forum nguồn (cursor/link, xếp sequence + ads alias)
  3. Lớp 1: Forward RR nhiều kênh đích
  4. Lớp 2: Ghi index — mỗi bài: seq, src_chat_id, src_msg_id, album_msg_ids[],
     item_type, ads_alias
  5. Notify admin group: bot/nguồn/ngày, link msg kế, deep link bot, trạng thái
  6. Recheck ads aliases sau lượt up (recheck_all_ads_aliases)
  7. Publish day (web hoặc auto) -> bot được phép trả user
  8. User /today hoặc /day 30-06-2026:
     - Check membership gate (clender)
     - Check VIP nếu require_vip_for_archive
     - Load day_items sorted by seq
     - _copy_item từng bài (delay >=1s, resume từ last_seq_sent)
     - Xong -> gửi link share t.me/bot?start=<numeric_token>

5.2 DELIVERY FALLBACK (clender _serve_album — bắt buộc)
-------------------------------------------------------

  Thử 1: copy_messages / copy_message (batch hoặc đơn)
         -> FloodWait: sleep, retry tối đa 3 lần
  Thử 2: forward_messages / forward_message
  Thử 3: từng message — copy_message, fail -> forward_message
         -> sleep 0.2s giữa msg
  Fail hết: báo user (bot chưa trong forum nguồn / file xóa / forward bị khóa)

5.3 MEMBERSHIP GATE (clender)
-----------------------------

  Mọi handler user-facing:
    -> gate_or_prompt()
      -> admin bypass
      -> không config channel -> pass
      -> cache hit -> pass/block
      -> get_chat_member -> member/admin/creator?
        No  -> gửi nút Join + "Đã join — kiểm tra" (callback mem_recheck)
              -> lưu pending action (start/day/...)
        Yes -> tiếp tục handler
  Config sai (bot không vào kênh): fail-open + log warning

5.4 ADS ALIAS & REVOKE
----------------------

  - Admin đặt alias -> msg link nguồn (có thể đổi bài)
  - Index ngày: item type=ads + ads_alias
  - Chấm dứt HĐ: ads_contracts.active=false -> lần xem sau strip ads,
    KHÔNG xóa tin user đã nhận
  - /all tail batch = ads alias riêng (all_*)

5.5 BACKUP (clender + UpBain export)
------------------------------------

  Scheduler: mỗi backup_interval_hours (default 24h), thread nền daemon.

  ZIP contents:
    backup_2026-06-30_1430.zip
    ├── platform.db              SQLite safe copy (backup API)
    ├── auto_config.json         tokens masked ***
    ├── archive_index.json       export days + items
    ├── bots.json                metadata, no tokens
    └── MANIFEST.json            version, git hash, checksum

  Telegram: gửi ZIP lên admin_forum_id / backup_forum_id,
  topic admin_zip_topic_id (tạo topic "backup" nếu chưa có).

  Web API:
    GET  /api/platform/backup           -> status (scheduler, last file, skip_reasons)
    POST /api/platform/backup           -> { "telegram": true/false } run now
    GET  /api/platform/backup/download  -> tải ZIP

6. DATA MODEL SQLite
================================================================================

  bots            id, token (config), username, source_forum_id, source_topic_id,
                  catalog_topic_id, branch (ads/plain), enabled, queue_order

  days            bot_id, date_vn, topic_label (30-06-2026),
                  status (draft/channel_done/indexed/published/closed), runs_count

  day_items       day_id, seq, src_chat_id, src_msg_id, album_msg_ids (JSON),
                  item_type (content/ads/all_tail_ads), ads_alias,
                  channel_sent, indexed

  ads_contracts   alias, src_msg_ids, src_chat_id, active, terminated_at

  users           telegram_id, username, ref_code, tier, vip_until,
                  spam_ban_until, allow_forward

  vip_plans       plan_type, name, stars_price, duration_days, enabled

  gift_codes      code, plan_id, max_uses, expires_at

  share_refs      ref_code (numeric), day_id, creator_user_id, click_count

  share_clicks    ref_code, user_id (unique per user — H34)

  user_deliveries user_id, day_id, last_seq_sent (resume khi bot die giữa chừng)

  contribution_queue  pending name proposals

  rollup_indexes  bot_id, period, catalog text posted

  /invite                   Link mời ?start=ref_<code>
  /me                       Tier, VIP, forward policy
  /leaderboard              Top share clicks

  STARS CHECKOUT:

    successful_payment -> grant_vip(source="stars")
