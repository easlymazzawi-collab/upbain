================================================================================

B4. Một nguồn forum = mấy bot token?

B5. Web quản lý thế nào?
    - ON/OFF từng lớp (up kênh / index / delivery)?
    - Restart từng bot / all?
    - Forum admin chung?
    [ĐÃ CHỐT] Có — web quản bot, ON/OFF lớp, restart đơn/all.

B6. Mấy userbot? Mấy admin web?
    [ĐÃ CHỐT] 1 userbot, nhiều admin web.

B7. Bot token chết — đổi token mới có mất DB / link không?
    [ĐÃ CHỐT] Hot-swap token + shared DB; deep link cập nhật @username.

B8. Ai up bài lên kênh đích (L1 publish)?
    - Chỉ userbot?
    - Bot token cũng up kênh (Bot API)?
    - Cả hai, bật/tắt từng lớp?
    [CẬP NHẬT — bạn vừa nói] Còn dùng bot token để up bài — cần chốt lại:
      □ Userbot thu nguồn + bot token up kênh
      □ Bot token vừa up kênh vừa delivery user
      □ Userbot up kênh như cũ + bot chỉ delivery

B9. Pin bài trên forum nguồn còn không?
    - Giữ pin userbot?
    - Thay bằng group admin notify (link bài kế)?
    (Trong spec: ưu tiên notify group, bỏ pin nguồn.)
